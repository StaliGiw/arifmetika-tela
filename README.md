# Кабинет «Арифметика тела»

## Скачать установщик

[Скачать версию 0.3.0 для Windows](downloads/Arifmetika-Tela-Setup-0.3.0.exe)

Запустите установщик и выберите папку. Он создаст ярлык «Арифметика тела» на рабочем столе и в меню «Пуск».

Пробная версия локальной картотеки для массажиста-реабилитолога. Приложение помогает вести карточки пациентов, записывать историю фактически проведённых приёмов и считать доход за месяц. Расписание намеренно не входит в продукт.

## Возможности

- быстрый поиск пациентов по имени, телефону и категориям;
- жалобы, противопоказания, заметки и цветные категории;
- история первичных и повторных приёмов;
- стоимость, полученная сумма и статус оплаты;
- месячная статистика дохода, среднего чека и задолженности;
- сохранение всей базы в JSON-файл и загрузка на другом компьютере;
- постоянный файл базы с автоматической резервной копией;
- удаление пациента или отдельного приёма после подтверждения;
- локальное хранение без отправки данных в интернет.

## Запуск пробной версии

После установки зависимостей приложение запускается как отдельное окно:

```powershell
npm start
```

Проверка расчётов:

```powershell
npm test
```

Сборка установочного EXE:

```powershell
npm run build:win
```

Готовый установщик создаётся в папке `dist` и добавляет ярлык на рабочий стол. Используется Electron 22 — последняя версия Electron с поддержкой Windows 7. Эта же сборка запускается в Windows 10 и 11.

## Статус

Это интерактивный прототип. Данные сохраняются в локальном хранилище приложения. Перед рабочим использованием с настоящими медицинскими сведениями потребуется добавить шифрование базы и автоматические резервные копии, а сборку отдельно проверить на реальном компьютере с Windows 7.

## Конфиденциальность

Репозиторий не содержит реальных данных пациентов. Не добавляйте экспортированные базы пациентов в Git.
